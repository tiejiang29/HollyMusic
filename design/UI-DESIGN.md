# HollyMusic Android 客户端 UI 设计规范（v3 · QQ音乐 11.0 设计语言）

> 参照对象：**QQ音乐 11.0 改版**（腾讯 MUX 团队设计总结，uisdc.com/qq-music-2）+ 用户提供的两张 QQ 音乐真实截图（首页/我的）。
> 核心理念：**轻盈、通透、年轻**——浅色主界面、荧光绿品牌色、轻拟物质感、封面取色魔法渐变播放页。
> 本文档配套浏览器原型：`design/prototype/index.html`（v3，手机壳内可切换预览）。
>
> v3 结构调整（用户指定）：**底部只留「首页 / 我的」双 tab**；搜索、音乐库、排行榜、收藏收进首页顶部横滑切换；设置移到「我的」右上角。

---

## 1. 设计定位

| 维度 | 决策 | 说明 |
|------|------|------|
| 参照 | QQ 音乐 11.0 | 双 tab + 首页顶部频道切换 + 全局迷你播放条 + 播放页左右滑（封面⇄歌词）+ 浅色通透卡片风 |
| 明暗 | **浅色为主**（背景近白），深色/跟随系统为设置项 | 播放页因封面取色自然偏彩色饱和 |
| 品牌色 | **荧光绿 #1FC774**，渐变 `#55E6A4 → #1FC774`（135°） | 所有图标/按钮/选中态用双色渐变+微阴影，不用单色平涂 |
| 质感 | **轻拟物**：渐变 + 内高光 + 柔和投影 | 卡片、按钮、图标统一 |
| 布局 | 大留白、区块化、界限分明 | 区块间靠留白与卡片分区，列表内才用细分割线 |

## 2. 色板（浅色主题 token）

| Token | 值 | 用途 |
|-------|-----|------|
| `bg` | `#F4F6F8` | 页面背景 |
| `card` | `#FFFFFF` | 卡片、列表条、弹层、tab 栏 |
| `primary` | `#1FC774` | 主色（文字态、进度、选中） |
| `primaryGrad` | `135° #55E6A4 → #1FC774` | 按钮、图标、选中 chip、资产行 |
| `accentBlue` | `#8AB4FF → #3D74E0` | 次级功能卡（我的收藏入口等，多色快捷区用） |
| `accentOrange` | `#FFC96B → #EE9422` | 第三功能卡（下载入口等） |
| `textPrimary` | `#1B1F28` | 主文字 |
| `textSecondary` | `#878D9C` | 副标题、说明 |
| `textTertiary` | `#BAC0CB` | 占位、箭头 |
| `divider` | `#F2F4F7` | 行间细分割线（仅列表内用，区块间靠留白） |
| `shadowCard` | `0 4px 18px rgba(27,42,60,.07)` | 卡片阴影 |
| `shadowGreen` | `0 8px 20px rgba(31,199,116,.28)` | 绿色主按钮/图标投影 |

### 封面取色（魔法色，播放页专用）

算法对齐 QQ 音乐 11.0：从当前歌曲封面提取主色 → 二次加工生成**亮色魔法色**（信息区/顶部）与**深色魔法色**（底部遮罩），播放页与迷你条背景随之整体换色。
原型示例：绿封面（夜的第七章）→ 绿系渐变播放页；紫封面 → 紫系渐变歌词页。每首歌自带氛围色，实现 `Palette API`（androidx.palette）提取 + 预置干预规则。

## 3. 信息架构

### 3.1 底部导航（双 Tab，参照用户提供的 QQ 音乐截图）

| Tab | 内容 |
|-----|------|
| **首页** | 顶部频道切换：推荐 / 音乐库 / 排行榜 / 收藏 + 搜索框；内容区随频道切换 |
| **我的** | 用户卡 + 快捷入口 + 最近播放 + 歌单；右上角齿轮进设置 |

Tab 样式：白底圆角上浮栏；选中态实心图标 + 黑字（未选线性灰字）。

### 3.2 全局常驻

- **迷你播放条**：随歌取色的彩色胶囊卡（v3 演示为绿系：`#B9EDD4→#8FD8B8` 渐变，实际运行时由封面魔法色生成），左侧圆形旋转封面、歌名+VIP 角标、暂停/队列按钮。点击 → 播放页。

### 3.3 页面地图（一期 MVP）

```
启动 → 登录页（服务器地址+账号密码，无 token 强制）
     → 主框架（首页 / 我的 双 Tab + 迷你播放条）
         首页（顶部频道切换 + 搜索框）
           ├─ 推荐：问候行 → 精选卡片横滑（飙升精选/热歌30…）→ 「大家都在听」歌曲列表
           ├─ 音乐库：服务器状态条 → 三色快捷卡 → 收藏列表
           ├─ 排行榜：分类 chips → hero 大卡 + 榜单网格 →（榜单详情二级页）
           └─ 收藏：歌曲/歌单/专辑/歌手 chips → 收藏列表
         我的（右上角⚙设置）
           ├─ 用户卡（渐变环头像/连接状态/收藏数 + 四入口行）
           ├─ 最近播放（横滑封面卡，▶/专辑/歌单角标）
           └─ 自建歌单 | 收藏歌单（tab + ＋/管理）→ 歌单列表
         二级页：搜索（覆盖式）/ 榜单详情 / 设置（←返回）/ 播放页（左右滑封面⇄歌词）/ 队列 Sheet
```

## 4. 页面规格

### 4.1 登录页

- 浅色通透：右上/左下两团柔光色晕（绿+蓝 radial）
- 中央渐变 Logo + "HollyMusic" 字标
- 服务器地址 / 用户名 / 密码：白色圆角输入框（聚焦绿描边+淡绿光圈）
- 登录按钮：荧光绿渐变全圆角 52dp；错误红字；底部灰字说明

### 4.2 首页（双 tab 之一）

**顶部结构（固定）**：
1. 频道切换行：推荐 / 音乐库 / 排行榜 / 收藏（选中：字号加大+加粗+绿色渐变短下划线；收藏带角标数）
2. 搜索框：白胶囊 + 彩色渐变小圆点 + 轮播热词（如「周杰伦 连续在榜20天🔥」）+ 右侧荧光绿渐变圆钮（放大镜）

**频道·推荐**（v3.1：无问候行、无连接状态、无热门趋势入口，进首页直接是内容）：
- 精选卡片横滑（蓝/橙渐变大卡，200px，内含旋转封面+渐变播放圆钮）：飙升精选 / 热歌30 / 华语经典…
- 「推荐歌单」区块：横滑歌单封面卡——首卡「每日 30 首」（品牌渐变底 + 「每日更新」角标），其余卡 = 封面 + 左上角播放量角标（▶ 328万）+ 底部歌单名（华语经典必听 / 私人雷达 / 深夜循环 / 跑步动感 / 欧美金曲）

**频道·音乐库**（v3.1：无服务器状态条，直接内容）→ 三色快捷卡（最近播放绿/我的收藏蓝/已下载橙，各带角标数）→ 「我的收藏」歌曲列表

**频道·排行榜**：分类 chips（官方榜/飙升榜/…）→ hero 深色大卡（跨两列）+ 白卡榜单网格（榜名+绿渐变播放钮+前三名）

**频道·收藏**：类型 chips（歌曲/歌单/专辑/歌手）→ 收藏歌曲列表（SQ/试 角标、⋮ 菜单）

### 4.3 我的（双 tab 之二，参照第二张截图）

1. 标题行：「我的」大标题（下带绿色渐变短线装饰）+ 右上角白色圆角**设置齿轮**按钮
2. 搜索框（点击进搜索页）
3. **用户卡**（白卡）：渐变环头像 + 用户名 + 退出小图标；副行绿点+「已连接 · 172.16.1.7:3099」；右侧大数字「32 收藏」
4. **四入口行**（卡内底部，细分割线上方）：收藏歌曲 / 下载管理 / 最近播放 / 我的歌单（线性图标+文字）
5. **最近播放**：标题「最近播放 ›」+ 横滑封面卡（118px 方卡：第一张带 ▶ 白圆角标「已播歌曲 500」，其余左上角「专辑/歌单」黑透明角标）
6. **歌单区**：「自建歌单 9」（选中态绿色下划线）|「收藏歌单 9」+ 右侧 ＋ / 管理 / › ；歌单行 = 58px 封面（左下 ▶ 圆钮）+ 名称 + 「N 首 · 首歌名」

### 4.4 设置页（我的→右上角进入）

- 顶栏：白色圆形返回钮 + 「设置」标题
- 分组白卡：音质偏好（SQ→HQ→128k 回退）/ 下载设置（Music/HollyMusic/）/ 外观（浅色/深色/跟随系统）
- 分组白卡：服务器管理（显示当前地址）/ 关于 HollyMusic（版本号）
- 退出登录：白卡红字

### 4.5 搜索页（覆盖式二级页）

- 搜索框 + 绿色「取消」；音源筛选 chips；结果列表 = 通用歌曲行
- 默认态：历史标签流 + 热门榜；输入中：联想下拉（歌手置顶，250ms 防抖）

### 4.6 播放页（核心，QQ 音乐 11.0 范式）

- **背景：封面取色魔法渐变**——顶部亮魔法色 → 底部深魔法色，叠加高光径向光斑；随歌换色
- 顶栏：收起箭头｜歌名+歌手（白字居中）｜更多（半透明玻璃圆钮）
- 中部：大封面（258dp、圆角 30px、白内高光+深投影、播放时呼吸缩放 1↔1.018）
- 页指示：胶囊圆点（当前页白色长条）；试听条：玻璃胶囊「♪ 试听 30s · 获取完整版 ›」
- 进度条：白色半透明轨道 + 白绿渐变已播 + 白色拖块
- 控制行：模式｜上一首｜**白色 76dp 大圆播放键（深绿图标，任何取色背景都成立）**｜下一首｜队列
- 左右滑：第 1 页封面 / 第 2 页歌词；队列走 BottomSheet

### 4.7 歌词页

- 同播放页取色背景；当前行白色加粗放大 + 光晕，其余行白色按距离降透明度（.38/.72）
- 手动滚动后显示「回到当前」玻璃胶囊；纯音乐显示「纯音乐，请欣赏」

### 4.8 通用歌曲行（全 App 复用）

```
[48dp 圆角12px 彩色封面] [标题 15sp semibold（可带灰底小徽章）] [⋮/心形]
                        [歌手-专辑 12sp 灰                  ]
```

- 正在播放：标题荧光绿 + 三柱音浪动画
- 角标：SQ（绿渐变）/ 试（灰）左上角悬挂

## 5. 关键交互与动效

| 场景 | 动效 |
|------|------|
| 迷你条 → 播放页 | 封面共享元素放大 + 背景魔法色渐显 |
| 播放页左右滑 | 水平 pager + 胶囊圆点滑动 |
| 取色过渡 | 切歌时背景魔法色 400ms 渐变过渡 |
| 播放/暂停 | 白键图标缩放弹跳 + 封面呼吸 |
| Tab 选中 | 图标上浮 2px + 绿渐变投影 |
| 音浪 | 三柱 scaleY 循环动画 |
| 列表按压 | 背景短暂 #F2F4F7 |

## 6. Compose 实现映射

- 主题：`lightColorScheme(primary = Color(0xFF1FC774), background = Color(0xFFF4F6F8), surface = Color.White)`；品牌渐变封装 `Brush.linearGradient(listOf(0xFF55E6A4, 0xFF1FC774))`
- 轻拟物封装：`Modifier.brandShadow(color)`（外投影）+ `.innerGlow()`（inset 高光用 drawWithContent 实现）
- 取色：androidx.palette 从封面 Bitmap 提取 → 生成亮/暗两个魔法色 → 播放页背景 `AnimatedContent` 过渡
- 导航/播放内核/列表/状态管理同 v1 结论：navigation-compose + Media3 ExoPlayer/MediaSessionService + LazyColumn + StateFlow
